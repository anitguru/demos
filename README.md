# demos

Interactive HTML demos generated by AI on my homelab.

- [Mixture of Experts — interactive explainer](moe-explainer/) — generated via Strata (local). Idea & prompt from [llama.app/docs/webui](https://llama.app/docs/webui).

- [Chatterbox Turbo — precision comparison](chatterbox-precision/) — measured 4-bit, 8-bit, and FP16 synthesis performance with embedded listening samples; includes a battery-power run archive.

- [Excitebike — a single-prompt HTML remake](excitebike/) — a complete Three.js dirt-bike racer in a single HTML file, written by minimax-m3.1-flash from one prompt and then reviewed and revised by the model itself; plays in the browser.

Live at https://anitguru.github.io/demos/
